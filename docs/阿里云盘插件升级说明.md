## 当前版本升级功能

### 1. 🎨 图形化用户界面

- **弹窗管理界面**：添加了可交互的弹窗界面，用于管理 RefreshToken
- **内联样式 + GUI 语义 CSS 变量**：使用内联样式和 GUI 语义 CSS 变量，自动跟随亮/暗主题
- **不创建 style 标签**：避免动态创建 style 标签，提升性能

### 2. 📝 多账号管理增强

- **批量添加/删除**：支持批量添加和删除多个 refresh_token，每行一个，自动去重
- **实时同步**：保存后直接写回插件配置，与配置页保持同步
- **自定义菜单项**：在插件设置的 menus 中添加"管理 RefreshToken"菜单项

### 3. 📁 配置文件自动管理

- **目录自动创建**：递归创建 `data/third/aliyunpan-signin/` 目录（如果不存在）
- **配置文件自动创建**：如果配置文件不存在，自动创建空配置文件
- **错误处理优化**：完善的错误处理和日志记录

### 4. 🔧 用户体验优化

- **移除点击外部关闭**：弹窗不再在点击外部区域时自动关闭，提升操作稳定性
- ** Escape 键关闭**：保留 Esc 键关闭弹窗的功能
- **右上角关闭按钮**：提供明确的关闭按钮

### 5. 🛡️ 稳定性增强

- **配置读取优化**：使用 `Plugins.ignoredError` 处理配置文件读取错误
- **目录创建递归**：确保所有父目录都正确创建
- **错误日志**：详细的错误日志记录，便于问题排查

当前版本的阿里云盘自动签到插件在初版基础上进行了全面升级，主要提升了用户体验、增强了功能性和稳定性。通过图形化界面、多账号管理和自动配置创建等功能，为用户提供了更加便捷和可靠的签到体验。
